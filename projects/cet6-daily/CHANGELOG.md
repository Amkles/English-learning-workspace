# 变更记录

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。存档 schema 单独编号，与版本号不绑定。

## v1.0.0 · 2026-11-06

首个可分发版本。

**今日任务**

- 进度卡（环形 N/5 + 五板块状态点 + 全清紫色态）
- 逾期条：昨天缺口默认并入今天，可切「只做今天」，无缺口整条隐藏
- 四列推送：阅读 2 篇、听力 1–2 个、翻译 1 段、写作 1 题，每条可一键计数
- 五项卡：目标 / 已完成 / 缺口，+1 与一键达标

**单词**

- 四个固定词库（四级全库 2607、四级重点 1302、六级全库 2345、六级重点 1313）+ 自建生词本
- 三种模式：卡片自评、四选一自测、清单速览
- 词卡含音标、词性、释义、词缀提示、语音合成；词性缺失时不渲染空块

**目标与资源**

- 每日单词量与五项目标实时生效，目标调大不追加推送
- 五个板块的素材分组，内置题库只读、自建来源可增删改
- 绑定素材支持八种输入形态、七步标题清洗、平台识别
- 查词与批改三个真实外链

**打卡统计**

- 四张数据卡、四档区间、汇总表
- 26 周热力图（颜色随达标项数加深，全清紫色）
- 各科达标率内联 SVG 条形图、逐日记录按月翻

**设置与说明**

- 考试日期、提醒开关与时间、导出 / 导入 JSON、清空示例、清空全部
- 使用说明独立一页九节

**数据**

- 词库 3920 词条，阅读 180，听力 145，翻译 90，写作 90
- 存档 schema v4，v1/v2/v3 自动迁移且不清空

**测试**

- 素材解析 13 条用例
- 400 天抽取压力测试（覆盖率、冷却、幂等、池版本号）
- 页面渲染与交互冒烟
